# How this profile is made

Every image on the profile is a self-contained SVG generated by the scripts in this folder. There are no third-party stat widgets, so nothing breaks when an external service is rate-limited or down.

- **Typography travels with the image.** Instrument Serif, Archivo and JetBrains Mono are subset to the exact glyphs each SVG uses and embedded as base64 WOFF, so every visitor sees the same type.
- **Dark and light.** Each asset is rendered twice (`assets/v3/dark`, `assets/v3/light`) and the README picks one with `<picture>` and `prefers-color-scheme`.
- **Motion without JavaScript.** CSS keyframes and SMIL only. Everything honors `prefers-reduced-motion`, and a still frame always shows the finished state.
- **Live cards.** `about`, `cp` and `activity` are redrawn daily by `.github/workflows/refresh-profile.yml` from the GitHub, Codeforces and AtCoder public APIs. If a source fails, the last good value in `data/live.json` is kept.

## Scripts

| Script | What it does |
| :--- | :--- |
| `build_static.py` | Hero, section headers, buttons, the Premise card, project cards, toolkit, experience and footer. |
| `update_live.py` | Fetches stats and renders the three live cards. `--offline` re-renders from `data/live.json`. |
| `make_portrait.py` | Turns the GitHub avatar into the halftone dot data in `data/portrait.json` (needs Pillow). |
| `preview.py` | Renders `README.md` through GitHub's Markdown API and screenshots it with headless Chrome or Edge. |
| `svgkit.py` | Shared themes, font embedding and drawing helpers. |

```bash
pip install fonttools pillow
python tools/build_static.py          # all static art (or name a few: hero p-forgeflow)
python tools/update_live.py           # live cards
python tools/preview.py dark          # writes _preview-dark.png
```

To change a project card, edit `PROJECTS` in `build_static.py`. To change experience, edit `EXPERIENCE`. LeetCode and CodeChef numbers have no public API for this handle, so they live in `STATIC` in `update_live.py`.
